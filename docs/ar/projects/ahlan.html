Ahlan

منصة لحجز خدمات النظافة والخدمات المنزلية عند الطلب، تغطي تنظيف السيارات والمنازل إضافة إلى طلبات العمالة المنزلية، مع تجربة حجز ودفع متعددة الخطوات وواجهة مستخدم أنيقة.

  • Flutter
  • Dart
  • REST APIs
  • State Management
  • Payment Integration
  • Responsive UI

نظرة عامة

Ahlan هي منصة لحجز الخدمات عند الطلب تربط المستخدمين بخدمات التنظيف والخدمات المنزلية، وتغطي تنظيف السيارات والمنازل — مثل تنظيف السيارات والكنب والسجاد والمراتب — إلى جانب طلبات العمالة المنزلية. ساهمت في تطوير تجربة التطبيق من خلال تنفيذ تدفقات اكتشاف وحجز خدمات أنيقة، وربط وظائف الدفع (Payment Integration)، وبناء مكونات UI قابلة لإعادة الاستخدام لمختلف أنواع الخدمات.

العمارة

تطبيق مبني باستخدام Flutter وDart، مع هيكلة التطبيق حول مكونات وشاشات UI قابلة لإعادة الاستخدام مشتركة بين فئات الخدمات المختلفة. تعتمد تدفقات اختيار الخدمة والحجز على ربط REST APIs وإدارة الحالة (State Management) للحفاظ على اتساق بيانات الخدمة وخطوات الحجز وحالة الدفع عبر التطبيق.

التحديات

دعم عدة أنواع خدمات مختلفة — تنظيف المركبات، وتنظيف المنازل، وطلبات العمالة المنزلية — ضمن تجربة حجز واحدة متسقة، لكل منها خطوات اختيار ومتطلبات إدخال واعتبارات تسعير ودفع خاصة بها.

الحلول

هيكلة تدفق الحجز حول مكونات وشاشات UI قابلة لإعادة الاستخدام وقابلة للتهيئة (Configurable)، بحيث تندمج كل فئة خدمة ضمن نفس التدفق الأساسي، ما يقلل التكرار مع الحفاظ على تجربة متسقة وسهلة التوسعة.

النتائج

تسليم تجربة حجز Flutter موجهة للإنتاج تغطي عدة فئات من خدمات التنظيف والخدمات المنزلية، مع ربط وظائف الدفع وواجهة مستخدم متسقة وأنيقة عبر تدفقات الخدمة.

الدور

مطوّر Flutter

المسؤوليات
  • تطوير وصيانة تجربة حجز أنيقة تغطي عدة تدفقات لخدمات التنظيف والخدمات المنزلية، تشمل تنظيف السيارات والكنب والسجاد والمراتب.
  • تنفيذ مكونات UI قابلة لإعادة الاستخدام وهيكلة الشاشات لدعم فئات خدمات مختلفة مع الحفاظ على تجربة مستخدم متسقة وجاهزة للإنتاج.
  • بناء وتحسين تدفقات حجز متعددة الخطوات (Multi-step Booking Flow)، تشمل اختيار الخدمة وإدخال بيانات المستخدم وتفاصيل الطلب وحالات الحجز.
  • ربط وظائف الدفع (Payment Integration) ضمن التطبيق لدعم عمليات الدفع مقابل الخدمات عبر تدفق الحجز الحالي.
  • ربط بيانات التطبيق وخدمات الـ Backend للتعامل ديناميكياً مع معلومات الخدمات وحالات الحجز وتدفقات العمل الموجهة للمستخدم.
  • معالجة الأخطاء (Debugging) وتحسين سلوك التطبيق عبر مختلف التدفقات، بما يعزز قابلية الصيانة وسهولة الاستخدام والجاهزية للإنتاج.
