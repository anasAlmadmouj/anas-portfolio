MondoWay

تطبيق شامل (Super App) ومنصة تجارية متكاملة تجمع بين طلبات المطاعم وتخصيص الوجبات، وتصفح الكتالوجات التجارية، ونظام الألعاب والمكافآت، ودليل الخدمات اللوجستية.

  • Flutter
  • Dart
  • Clean Architecture
  • BLoC
  • REST APIs
  • Payment Gateways

Visual Showcase & Screen Architecture

8 Production Screens

نظرة عامة

تطبيق MondoWay هو تطبيق شامل متعدد التجار والخدمات يعمل في الأردن، يوفر تجربة رقمية موحدة تجمع بين طلب الطعام من المطاعم مع تخصيص المكونات والوجبات، وتصفح المنتجات التجارية المتنوعة، والمشاركة في الألعاب والجوائز، والوصول إلى خدمات الشركات واللوجستيات.

العمارة

هيكلية Clean Architecture معيارية مقسمة حسب الميزات مع نمط BLoC. استخدام نمط المستودعات (Repository Pattern) لتجريد نقاط الاتصال، مع التخزين المحلي السريع للقوائم والتصميم الموحد للواجهات.

التحديات

تلبية المتطلبات التجارية المتنوعة عبر أقسام التطبيق المختلفة (قوائم المطاعم المعقدة، والكتالوجات التجارية، وألعاب السحوبات) دون زيادة استهلاك الذاكرة أو تعقيد الاعتماديات.

الحلول

تصميم هيكل برمجي معياري مستقل لكل ميزة، مع تحميل المكونات عند الحاجة وإدارة معزولة لحالة كل وحدة تجارية.

النتائج

توحيد عدة وحدات تجارية — طلبات الطعام، الكتالوجات التجارية، الألعاب والمكافآت، والخدمات اللوجستية — ضمن تطبيق Flutter واحد قابل للتوسع ومتجاوب على الهاتف والتابلت.

الدور

مهندس تطبيقات Flutter

المسؤوليات
  • تطوير البنية المعمارية لتطبيق Super App يدعم وحدات تجارية متعددة ومستقلة داخل قاعدة كود واحدة.
  • هندسة شاشة تخصيص الوجبات والمنتجات ديناميكياً مع دعم الخيارات المتعددة وحساب الأسعار التفاعلي.
  • بناء نظام سلة التسوق وإنهاء الطلبات مع خيارات الاستلام من الفرع أو التوصيل، ودعم قسائم الخصم وبوابات الدفع.
  • دمج نظام الألعاب التفاعلي والمكافآت وسحوبات الجوائز مع تتبع ولاء المستخدمين.
