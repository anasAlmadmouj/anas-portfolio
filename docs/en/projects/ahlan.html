Ahlan

An on-demand service booking platform connecting users with vehicle and household cleaning services and domestic worker requests, featuring a polished multi-step booking and payment experience.

  • Flutter
  • Dart
  • REST APIs
  • State Management
  • Payment Integration
  • Responsive UI

8 Production Screens

Overview

Ahlan is an on-demand service booking platform that connects users with cleaning and domestic services, covering vehicle and household cleaning — car, sofa, carpet, and mattress cleaning — alongside domestic worker requests. I contributed to the development of the application experience, implementing polished service discovery and booking flows, integrating payment functionality, and building reusable UI components across the platform's different service types.

Architecture

Built with Flutter and Dart, structuring the application around reusable UI components and screens shared across different service categories. Booking and service-selection flows are backed by REST API integrations and state management to keep service data, booking steps, and payment status consistent across the app.

Challenges

Supporting several distinct service types — vehicle cleaning, household cleaning, and domestic worker requests — within a single consistent booking experience, each with its own selection steps, input requirements, and pricing and payment considerations.

Solutions

Structured the booking flow around reusable, configurable UI components and screens so each service category could plug into the same underlying flow, reducing duplication while keeping the experience consistent and easy to extend.

Results

Delivered a production-oriented Flutter booking experience spanning multiple cleaning and domestic service categories, with integrated payment functionality and a consistent, polished UI across service flows.

Role

Flutter Developer
