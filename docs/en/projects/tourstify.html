Tourstify

A dynamic social travel companion platform featuring real-time traveler matchmaking, interactive trip planners, and voice messaging with audio waveform transcription.

Visual Showcase & Screen Architecture

6 Production Screens

Overview

Tourstify is an innovative mobile platform built for solo travelers and explorers to connect, plan journeys, and share experiences. The application combines an interactive social feed with an intelligent "Travel Twin" matching engine, AI-powered voice messaging with waveform transcription, an AI-powered chatbot, multi-day trip itinerary planners, and in-app payment integrations.

Architecture

Built with Flutter and Dart following Clean Architecture with strict separation of Presentation, Domain, and Data layers. Uses BLoC for deterministic event-driven state transitions, Dio for REST API communications with automatic token refresh, and custom audio player controllers.

Challenges

Rendering fluid audio waveforms with real-time seek capability, managing asynchronous voice uploads and playback states across active chat lists, and ensuring a responsive UI during feed pagination.

Solutions

Implemented custom audio stream controllers with isolate-based audio processing, cached media pipelines, and optimistic UI updates for chat and matching interactions.

Results

Delivered a production-ready mobile experience combining real-time voice messaging, AI-powered chat assistance, payment integrations, and trip planning in a single cohesive Flutter application.

  • Built multi-day itinerary planner with custom schedule timelines, notes, and interactive location pins.
  • Integrated an AI-powered chatbot and in-app payment gateways for premium features and bookings.
